# MVP video: narrated MP4, at most 90 seconds

Use a simple screen recording with your own voice explaining the app. The assignment asks for working software, not a commercial. Aim for 75–85 seconds.

## Prepare

1. Start server and phone app. Restart server for a clean 1,000-coin account, then refresh app.
2. Use the first matchup. Choose Buffalo Bills and stake 100 so the deterministic home-team win demonstrates a reward.
3. Keep simulation labels visible and say that these scores are simulated. Do not claim the real NFL feed is working until it is implemented and verified.

## Recording outline

- 0–10 seconds: “BetSafe is our Flutter app for NFL picks using virtual coins. It opens straight into a demo account.”
- 10–30: Show Games, choose a matchup/team/stake, explain the daily limit and submit.
- 30–50: Show Start simulation, then Finish simulation. Explain that the Node server validates picks and handles the balance/result.
- 50–65: Show the winning result, return to the app and open Collection.
- 65–80: Show My picks; briefly show repository/task list and a successful automated build if required for this submission.
- Finish by 90 seconds. Export as MP4 and play the file to check narration, screen visibility and duration before uploading.

## Team participation

Choose the presenter from any development role based on microphone quality and presentation confidence; agree separately who records/edits. Every member supplies a short explanation of their contribution; use one narrator unless the rubric requires everyone to speak. Confirm submission ownership so only the intended person uploads.
